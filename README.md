# JCB Connect Pro

Flutter starter app for:
- Machine model dashboard
- Machine-specific service-kit selection
- 100/500/1000/1500/2000 hour service tabs
- Inventory search
- Add-part validation
- Discounted pricing
- Delete confirmation
- Material 3 UI
- IndexedStack navigation

## Run
1. Install Flutter 3.x.
2. Extract the ZIP.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Important
The machine photos and service-kit prices in this demo are sample data. Replace them with images/data you have the rights to use and your real catalogue.

Inventory currently lives only in app memory and resets when the app restarts. For a production app, connect Firebase/Firestore or SQLite and add authentication/roles.
